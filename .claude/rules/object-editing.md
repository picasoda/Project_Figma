# 객체 편집 규칙

## 이동
- 객체 내부 드래그 → 셀 단위 스냅 이동
- 다른 객체와 겹침 차단
- 캔버스 밖 이탈 차단

## 크기 조절
- 객체 가장자리 드래그 → 셀 단위 스냅
- 다른 객체와 겹침 차단
- 캔버스 밖 이탈 차단

## 삭제
- Delete 키 또는 속성 패널 삭제 버튼
- 삭제 시 색상 팔레트로 반환

## 다중 선택
- Shift+클릭으로 여러 객체 선택
- 일괄 삭제 가능
- M키 또는 속성 패널 "병합" 버튼으로 복합 객체로 합치기 가능

## 병합 해제
- 속성 패널 병합해제 버튼
- 객체를 빈 셀들로 복원

## 도려내기
- 드래그로 영역 선택(빨간 하이라이트) → D키
- 선택 영역과 겹치는 객체에서 해당 셀 범위 제거
- 남은 영역을 최대 4개 rect로 분해 → compositeRects로 저장
  - 위: (sc, sr, ec, dsr-1)  — 도려내기 위쪽
  - 아래: (sc, der+1, ec, er) — 도려내기 아래쪽
  - 좌: (sc, dsr, dsc-1, der) — 도려내기 좌측
  - 우: (dec+1, dsr, ec, der) — 도려내기 우측
- 남은 영역이 0이면 객체 전체 삭제 (색상 팔레트 반환)
- 선택 영역이 객체와 전혀 겹치지 않으면 무동작
- Undo 대상

## 폴더 (객체 목록 그룹화)
- 목록 패널 헤더 "📁+" 버튼 → 새 폴더 생성 (인라인 이름 편집 자동 시작)
- 폴더 이름 더블클릭 → 인라인 편집
- 폴더 "×" 버튼 → 삭제 (소속 객체는 미분류로 복귀)
- 폴더 헤더 클릭 → 접기/펼치기
- 객체를 폴더 헤더에 드래그 앤 드롭 → 폴더에 추가
- 객체 목록에서 우클릭 → 컨텍스트 메뉴 (폴더 선택 또는 폴더에서 제거)
- 폴더 내 객체는 목록에서 들여쓰기로 표시
- 미분류 객체는 폴더 위에 표시
- 폴더 생성·삭제·배정 모두 Undo 대상

## Undo
- Ctrl+Z, 최대 50단계
- 대상: 생성, 삭제, 이동, 크기 조절, 병합, 도려내기, 병합 해제, 속성 변경, 폴더 조작
- 제외: 줌, 팬, 격자 토글, 프로젝트명 변경
- 50단계 초과 시 가장 오래된 기록 제거
