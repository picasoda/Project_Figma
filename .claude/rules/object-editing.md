# 객체 편집 규칙

## 이동
- 객체 내부 드래그 → 셀 단위 스냅 이동
- 다른 객체와 겹침 차단
- 캔버스 밖 이탈 차단

## 크기 조절
- 객체 가장자리 드래그 → 셀 단위 스냅
- 다른 객체와 겹침 차단
- 캔버스 밖 이탈 차단

## 삭제
- Delete 키 또는 속성 패널 삭제 버튼
- 삭제 시 색상 팔레트로 반환

## 다중 선택
- Shift+클릭으로 여러 객체 선택
- 일괄 삭제만 가능 (이동·크기 조절 불가)

## 병합 해제
- 속성 패널 병합해제 버튼
- 객체를 빈 셀들로 복원

## Undo
- Ctrl+Z, 최대 50단계
- 대상: 생성, 삭제, 이동, 크기 조절, 병합 해제, 속성 변경
- 제외: 줌, 팬, 격자 토글, 프로젝트명 변경
- 50단계 초과 시 가장 오래된 기록 제거
