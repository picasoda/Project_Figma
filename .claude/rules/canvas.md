# 캔버스 규칙

## 프리셋 기본값
- Desktop: 1920×3000, 48열×75행
- Tablet: 768×2800, 24열×88행
- Mobile: 390×2532, 18열×117행
- Custom: 사용자 입력 (최소 2×2)
- 모든 프리셋은 실제 웹 페이지 스크롤 길이 기준 (뷰포트 3배 높이)

## 캔버스 크기 조절 (새파일 모달)
- 프리셋(Desktop/Tablet/Mobile): 가로는 기기 표준값 고정(읽기 전용 표시), 세로 높이만 입력 가능 (최소 100px)
- 세로 입력란 blur 시 빈값/100 미만이면 해당 프리셋 기본값으로 복구
- Custom: 가로·세로 모두 자유 입력
- 프리셋 전환 시 세로 입력값이 해당 프리셋 기본값으로 초기화됨

## 배율
- 범위: ×0.5 ~ ×3.0, 0.1 단위
- 프리셋 격자 수에 배율 곱하여 실제 격자 수 결정
- 격자 수는 모달 내 인풋으로 직접 수정 가능 (2~200 범위, blur 시 빈값 복구)
- Custom 모드에서는 배율 미적용, 직접 입력값 사용

## 렌더링
- Canvas API 사용, 캔버스 영역의 85% 크기로 표시
- 해상도 비율 항상 유지
- window resize 시 자동 재렌더링
- 렌더 순서: 객체 fill → 객체 테두리 → 선택·이동·드래그 프리뷰 → 격자선 → 텍스트 레이블
- 텍스트는 격자선보다 위(나중)에 렌더링되어 항상 가독성 유지

## 격자선
- 색상: #e0e0e0, G키로 토글
- 굵기: `1 / viewZoom` (화면 기준 항상 1px 유지, 줌 자동 보정)

## 텍스트 레이블
- 색상: 검은색 `rgba(0,0,0,0.9)`, 그림자: 흰색 `rgba(255,255,255,0.9)` (가독성 보정)
- 화면 기준 14→12→10→8px 자동 축소 후 말줄임
- 캔버스 픽셀 크기 = 기준값 / viewZoom (줌해도 화면 크기 일정)
- shadowBlur도 줌 보정 적용 (3 / viewZoom)

## 객체 테두리·선택선
- lineWidth: `2 / viewZoom` (화면 기준 2px)
- 점선 dash 간격도 줌 보정 적용

## 줌·팬
- 줌: Ctrl+마우스 휠, 툴바에 % 표시
- 팬: 휠클릭(가운데 버튼)+드래그
- 맞추기: 줌 100% + 팬 원점 리셋
