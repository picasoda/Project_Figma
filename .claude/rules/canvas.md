# 캔버스 규칙

## 프리셋 기본값
- Desktop: 1920×1080, 48열×27행
- Tablet: 768×1024, 24열×32행
- Mobile: 390×844, 18열×39행
- Custom: 사용자 입력 (최소 2×2)

## 배율
- 범위: ×0.5 ~ ×3.0, 0.1 단위
- 프리셋 격자 수에 배율 곱하여 실제 격자 수 결정
- Custom 모드에서는 배율 미적용, 직접 입력값 사용

## 렌더링
- Canvas API 사용, 캔버스 영역의 85% 크기로 표시
- 해상도 비율 항상 유지
- window resize 시 자동 재렌더링
- 격자선: #3a3a5a, 1px, G키로 토글

## 줌·팬
- 줌: Ctrl+마우스 휠, 툴바에 % 표시
- 팬: 휠클릭(가운데 버튼)+드래그
- 맞추기: 줌 100% + 팬 원점 리셋
