# 색상 팔레트 규칙

## 16색 고대비 팔레트 (순서대로 자동 배정)
#FF0000, #0000FF, #00CC00, #FFFF00,
#8800FF, #FF8800, #00FFFF, #FF00FF,
#884400, #FF88AA, #88FF00, #0088FF,
#AA00AA, #00AA44, #FFAA00, #4444FF

## 배정 규칙
- 객체 생성 시 팔레트에서 미사용 색상 순차 배정
- 삭제 시 해당 색상 팔레트로 반환
- 속성 패널에서 색상 변경 가능

## 배경 객체 색상
- #CCCCCC 고정, 변경 불가
- 팔레트와 별도 관리
