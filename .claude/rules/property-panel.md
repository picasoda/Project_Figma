# 속성 패널 규칙

## 열기·닫기
- 객체 클릭 → 우측 패널 열림
- 다른 객체 클릭 → 해당 객체로 패널 전환
- 빈 영역 클릭 또는 ESC → 선택 해제 + 패널 닫힘

## 필드
- 이름 (Label): 텍스트 입력
- 설명 (Description): 텍스트 입력 (AI 프롬프트에 사용)
- 색상: 16색 팔레트에서 선택, 사용 중 색상은 비활성 표시

## 버튼
- 삭제: 객체 제거 + 색상 반환
- 병합 해제: 객체를 빈 셀들로 복원

## 텍스트 표시 (캔버스 내)
- 1순위: 폰트 자동 축소 (최소 크기까지)
- 2순위: 말줄임(…) 처리
- 3순위: 극소 객체는 약자만 표시
- 클릭 시 속성 패널에서 전체 텍스트 확인
