# 객체 생성 규칙

## 생성 흐름
1. 빈 셀 위에서 좌클릭+드래그 → 셀 범위 하이라이트
2. Enter 키 또는 툴바 객체생성 버튼 → 객체 확정
3. 단순 클릭(드래그 없음)은 객체 선택이지 생성이 아님

## 차단 조건
- 선택 영역이 0셀이면 생성 불가
- 기존 객체와 겹치면 생성 완전 차단
- 16색 모두 사용 시 생성 차단

## 생성 시 동작
- 팔레트에서 미사용 색상 자동 배정
- 테두리 자동 표시

## 배경 객체
- 툴바 버튼으로 생성
- 색상 #CCCCCC 고정, 프로젝트당 1개 제한
- 설명만 입력 가능

## 객체 데이터 구조
- id: 고유 식별자
- label: 객체 이름
- description: 자연어 설명
- color: 팔레트 색상 hex
- startCol, startRow, endCol, endRow: 셀 범위
