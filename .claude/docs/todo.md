# 개발 진행도

## 1단계: 파일 생성 + 격자 렌더링
- [x] 툴바 레이아웃 (새파일, 프로젝트명, 객체생성, 배경생성, 줌, 맞추기, 격자, 단축키, 저장, 불러오기, Export)
- [x] 파일 만들기 모달 (프리셋, 배율, 이름, 유효성 검사)
- [x] Canvas API 격자 렌더링 (비율 유지, 리사이즈 대응)
- [x] 프로젝트 미생성 시 빈 화면 + 안내 텍스트
- [x] 플로팅 저장 경고 (저장 후 만들기 / 그냥 만들기 / 취소)

## 2단계: 영역 선택 + 객체 생성
- [x] 빈 셀 위에서 좌클릭+드래그 → 셀 범위 하이라이트
- [x] 16색 고대비 팔레트 정의
- [x] Enter 또는 툴바 객체생성 버튼 → 객체 생성
- [x] 자동 색상 배정 + 테두리 표시
- [x] 겹침 완전 차단 + 0셀 생성 방지
- [x] 객체 데이터 구조 (id, label, description, color, cells)
- [x] 16색 모두 사용 시 색상 순환 재사용

## 3단계: 객체 선택 + 속성 패널
- [x] 객체 클릭 → 선택 하이라이트 + 우측 속성 패널 열기
- [x] 패널: 이름(Label), 설명(Description), 색상 선택
- [x] 빈 영역 클릭 또는 ESC → 선택 해제 + 패널 닫기
- [x] 다른 객체 클릭 → 패널 전환
- [x] 패널 내 삭제 버튼

## 4단계: 객체 편집 ← 현재
- [ ] 객체 드래그 이동 (셀 단위, 캔버스 내 제한)
- [ ] 가장자리 드래그 크기 조절 (셀 단위, 겹침 차단)
- [ ] 객체 선택 후 Delete 키 = 삭제
- [ ] Shift+클릭 다중 선택 → 일괄 삭제만 가능
- [ ] Undo (Ctrl+Z, 최대 50단계, 히스토리 관리)

## 5단계: 객체 목록 + 배경 객체 + 텍스트
- [ ] 우측 객체 목록 바 (색상 아이콘 + 이름)
- [ ] 목록 클릭 → 캔버스 하이라이트
- [ ] 드래그로 목록 순서 변경 (프롬프트 순서 반영)
- [ ] 스크롤 지원
- [ ] 배경 객체 생성 (툴바 버튼, #CCCCCC 고정, 1개 제한, 설명만 입력)
- [ ] 객체 내 텍스트 표시: 자동 축소 → 말줄임 → 약자
- [ ] 객체 클릭 시 전체 텍스트 확인

## 6단계: 저장 / 불러오기
- [ ] Ctrl+S 또는 툴바 → .gridframe.json 다운로드
- [ ] 툴바 불러오기 → 파일 선택기
- [ ] 드래그앤드롭 불러오기
- [ ] 덮어쓰기 확인 팝업
- [ ] localStorage 자동 저장 (주기적)
- [ ] 재접속 시 복원 확인 팝업

## 7단계: Export
- [ ] Export 모달 (세그멘테이션 맵 + 프리뷰 + 프롬프트)
- [ ] 세그멘테이션 맵 PNG (색상 블록만, 테두리 없음)
- [ ] 프리뷰 PNG (테두리 + 색상 + 설명 + 자동 범례)
- [ ] 3×3 영역 매핑 (캔버스 비율 기반 위치 판정)
- [ ] 객체 중심점 기반 위치 (top/center/bottom × left/center/right)
- [ ] 다중 영역 결합 처리
- [ ] 프롬프트 자동 생성 (색상명 + 위치 + 설명)
- [ ] 프롬프트 직접 편집 가능
- [ ] 클립보드 복사 버튼

## 8단계: 줌·팬 + 격자 토글 + 단축키 패널
- [ ] Ctrl+휠 줌 인/아웃 (% 표시)
- [ ] 휠클릭+드래그 캔버스 팬
- [ ] 맞추기 버튼 (줌·팬 리셋)
- [ ] G키 격자선 토글
- [ ] 툴바 단축키 버튼 → 단축키 안내 패널

## 9단계: UI 마무리
- [ ] 전반적 UI/UX 다듬기
- [ ] 반응형 레이아웃 점검
- [ ] 엣지 케이스 버그 수정 (빈 객체, 경계 겹침 등)
- [ ] GenSpark 테스트 3건 + 결과 문서화
