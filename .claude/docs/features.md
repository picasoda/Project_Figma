# GridUI 명세(최소한의 내용)

## 1. 툴바
- 파일: 새 파일(프리셋·배율·이름), 프로젝트명 편집, JSON 저장/불러오기, localStorage 자동 저장·복원
- 편집: 영역 선택 후 객체 생성 버튼, 배경 객체 생성 버튼
- 뷰: 줌 인/아웃(% 표시), 캔버스 맞추기(줌·팬 리셋), 격자선 토글
- 출력: Export 버튼 → 모달
- 도움말: 단축키 패널 열기 버튼

## 2. 파일 만들기
- 프리셋: Desktop 1920×1080 (32×18), Tablet 768×1024 (24×32), Mobile 390×844 (18×39), Custom
- 배율: ×0.5 ~ ×3.0, 0.1 단위, 실시간 격자 수·해상도 표시
- Custom: 해상도(px)와 격자 수(열×행) 직접 입력
- 유효성: 이름 필수, 금지 문자 차단, 최소 2×2 격자
- 작업 중 새파일 시 플로팅 경고 (저장 후 만들기 / 그냥 만들기 / 취소)

## 3. 캔버스
- Canvas API 기반 격자 렌더링, 해상도 비율 유지
- 브라우저 리사이즈 시 자동 재조정
- 줌: Ctrl+마우스 휠, 퍼센트 표시
- 팬: 휠클릭+드래그
- 맞추기: 줌·팬 리셋
- 격자선: G키 또는 툴바로 표시/숨김 토글

## 4. 객체 시스템
- 빈 셀 좌클릭+드래그 → 셀 범위 선택 → Enter 또는 툴바 버튼으로 생성
- 16색 고대비 팔레트에서 자동 배정, 테두리 자동 생성
- 겹침 완전 차단, 0셀 생성 불가, 16색 소진 시 색상 순환 재사용
- 드래그 이동(셀 단위), 가장자리 드래그 크기 조절(셀 단위)
- 이동·크기 조절 시 겹침·캔버스 이탈 차단
- Delete 키 삭제 → 색상 팔레트 반환
- Shift+클릭 다중 선택 → 일괄 삭제 또는 M키/버튼으로 병합
- 병합: 여러 객체 → 하나의 복합 객체 (compositeRects 구조)
- 도려내기: 드래그 선택 → D키 → 객체에서 해당 영역 제거
- 병합 해제
- Undo: Ctrl+Z, 최대 50단계

## 5. 속성 패널 (우측 사이드)
- 객체 클릭 시 열림, 다른 객체 클릭 시 전환
- 빈 영역 클릭 또는 ESC로 닫힘
- 필드: 이름(Label), 설명(Description), 색상(16색 팔레트, 사용 중 비활성)
- 삭제·병합해제 버튼

## 6. 텍스트 표시
- 객체 내부에 설명 텍스트 렌더링
- 공간 부족 시: 폰트 자동 축소(최소 크기) → 말줄임(…) → 약자
- 클릭 시 속성 패널에서 전체 텍스트 확인

## 7. 객체 목록 바 (우측)
- 모든 객체를 색상 아이콘 + 이름으로 나열
- 클릭 시 캔버스에서 하이라이트
- 드래그로 순서 변경 → 프롬프트 생성 순서에 반영
- 스크롤 지원

## 8. 저장·불러오기
- 형식: .gridframe.json
- 저장: Ctrl+S 또는 툴바 → JSON 다운로드
- 불러오기: 툴바 파일 선택기 또는 드래그앤드롭
- 덮어쓰기 확인 팝업
- localStorage 주기적 자동 저장
- 재접속 시 복원 확인 팝업

## 9. Export
- 모달: 프리뷰 + 프롬프트 표시
- 프리뷰 PNG: 테두리 + 색상 + 객체 이름 (격자선·범례 없음)
- 3×3 영역 매핑: 캔버스를 가로·세로 3등분, 객체 중심점 기준 위치 판정
- 다중 영역 결합 (예: top-entire, left-entire)
- 프롬프트 자동 생성: 색상명 + 위치 + 설명
- 프롬프트 직접 편집 가능
- 클립보드 복사 버튼

## 10. 조작
- 마우스: 좌클릭(선택/패널), 좌클릭+드래그(영역 선택/이동/크기 조절), 휠클릭+드래그(팬)
- 키+마우스: Ctrl+휠(줌), Shift+클릭(다중 선택)
- 키보드: R(객체 생성), D(도려내기), M(병합), Delete(삭제), Ctrl+Z(Undo), Ctrl+S(저장), G(격자 토글), ESC(선택 해제)
